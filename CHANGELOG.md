# Changelog

## 0.4.0

- Expanded the reusable library from 23 to 75 prepared automations across CRM, communications, monitoring, WordPress, commerce, agency operations, social/content and reporting.
- Added 52 deterministic starter templates with TaskRail 3 manifests, catalog metadata, local READMEs, health contracts and tests.
- Kept write-capable workflows deny-by-default; publishing, messaging, offboarding and other external mutations require separate explicit authorization.
- Updated the README to enumerate the complete 75-automation catalog.

## 0.3.0

- Added paid-media automation suite: budget pacing, creative fatigue, tracking-failure detection, campaign launch QA, lead-quality feedback, Google Ads agent and cross-channel ads brief.
- Added SEO/local visibility suite: Search Console opportunity and decline detection, technical/indexing watch, content refresh queue, cannibalization detector, internal-link recommendations, local SEO monitor, GBP anomaly detector, review reply drafts, SEO brief generator and monthly SEO reporting.
- Expanded `npm test` to run all automation tests recursively.

## 0.2.0

- Updated compatibility baseline to TaskRail 3.0.0 / `3.0.x` publication contracts.

## 0.1.0

- Initial reusable TaskRail automation library.
